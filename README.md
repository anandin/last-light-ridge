# Last Light Ridge

A small, complete game from Eve's Game Dev Factory — the proof piece.

You are the valley's watcher at golden hour. Walk the Marble valley, climb to the
ridge stone (follow the golden beam), then use the scope to ring six signal bells
on posts across the valley. Ring them all and the pass is safe for the night.

**Controls:** WASD walk · Shift brisk · mouse look · at the ridge, hold right
mouse (or Q) for the scope · left click fires.

Built with Three.js + Spark (Gaussian splat scenery) over a World Labs Marble
world; the invisible collider mesh from the same world is the ground you walk on.
Design notes: DESIGN.md in the factory project folder.
